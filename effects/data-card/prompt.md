# 数据卡片

## 目标
用一张卡片呈现单个关键指标：主数值、单位、环比涨跌与一条迷你趋势线，并让指针或键盘可以逐点读取趋势上的具体数值。

## 触发与行为
- 指针进入卡片：边框与阴影提升到高亮态；移到趋势区内时，趋势线略微加重，最近的数据点被高亮并显示其读数浮层。
- 指针在趋势线区域内水平移动：按横坐标就近吸附到某个数据点，显示垂直参考线与圆点，并在点的上方或下方显示日期与数值。
- 指针离开趋势线或卡片：参考线、圆点与浮层在 120ms 内淡出并完全隐藏，不残留读数。
- 键盘：Tab 聚焦趋势区后，← → 逐点移动，Home / End 跳到首尾，Esc 退出逐点状态；当前点通过 aria-live 播报「10-15，64.8%」。
- 涨跌方向由 {{trend}} 决定：1 显示向上箭头与强调色，-1 显示向下箭头与警示色，0 显示横杠与中性色；箭头、{{delta}} 与「较上周」文案必须同时出现。

## 参数
- {{value}}：主数值，默认 68.4，建议 0–999，使用卡片内最大字号。
- {{unit}}：单位后缀，默认 %，建议 1–3 个字符（如 %、万、ms），紧跟数值并降低字号。
- {{trend}}：涨跌方向，默认 1；1 上涨、-1 下跌、0 持平。
- {{delta}}：环比变化幅度，默认 4.2，建议 0–99，只显示绝对值，正负号由 {{trend}} 决定。
- {{decimals}}：主数值与浮层读数的小数位，默认 1，建议 0–2。

## 技术中性约束
- 不引入任何第三方依赖；趋势线用内联 SVG 折线与渐变面积，不使用 canvas。
- 数值区使用等宽数字字形并预留宽度，逐点读取时不改变卡片尺寸、不重排相邻元素。
- 指针移动用 requestAnimationFrame 合并，离开时取消未执行的帧。
- SVG 坐标由数据数组计算，数据点增减不需要修改路径常量。
- 浮层使用绝对定位，不撑开卡片，不改变折线区域高度。

## 降级与可访问性
- 趋势区可聚焦，并附可见文字说明「使用左右方向键查看每日数值」。
- prefers-reduced-motion 下：不做位移与缩放动效，高亮只改颜色与边框，浮层直接出现与消失。
- 浮层文字与卡片背景对比度不低于 4.5:1，浮层不得被卡片边缘裁切。
- 数值、单位与涨跌必须同时有文字标签，不把信息只放在箭头图标里。
- 触摸设备点按趋势区即可显示该点读数，不依赖悬停。

## 验收
- 指针在趋势线上移动时圆点始终落在最近的数据点上，不悬空。
- 浮层在左右两端自动避让，不出界、不被裁切。
- 键盘 ← → 可以逐点移动，播报内容与浮层一致。
- 指针离开后 150ms 内完成清除，无参考线与浮层残留。
- 开启减弱动态效果后卡片没有位移或缩放。
- 数据点数量变化后折线仍完整落在绘图区内。

## 不要做
- 不要加多指标切换、时间范围筛选或多卡片联动。
- 不要做 3D 倾斜、视差或跟随光斑。
- 不要只靠颜色区分涨跌，箭头与「较上周」文案必须同时存在。
- 不要给趋势线加粒子、噪点或滚动光效。
