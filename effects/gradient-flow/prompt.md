# 渐变流动背景

## 目标
用铺满视口、以 {{speed}} 为周期缓慢漂移的渐变光晕做环境层，让首屏有层次和呼吸感，同时不抢正文。

## 触发与行为
- 进入：页面加载即开始，不需要滚动、悬停或点击触发。
- 持续：底色渐变沿 {{angle}} 方向做位移与轻微缩放，三组光晕以互不相同的周期漂移，避免节奏一眼被看穿。
- 循环：所有关键帧首尾状态完全一致，循环接缝处不跳变、不闪白。
- 暂停：用户点击暂停即冻结在当前帧，恢复后从该帧继续，不重置进度；标签页不可见时自动冻结。
- 不随滚动、鼠标或内容变化改变速度与方向。

## 参数
- {{speed}}：一个完整循环的时长，默认 12s，建议 8–20s；低于 6s 会明显抢注意力。
- {{angle}}：主渐变方向，默认 135deg，建议 0–360deg，通常取 90–160deg 让光从左上往右下压。
- {{intensity}}：光晕整体强度，默认 0.55，建议 0.3–0.8，需要保证正文区域对比度不下降。

## 技术中性约束
- 只使用 transform 与 opacity 驱动，不改 background-position，不逐帧写入样式。
- 动画全部由 CSS 关键帧完成，脚本只负责暂停与恢复，不参与每一帧的计算。
- 背景层固定铺满并溢出裁剪，尺寸不足时用放大倍数兜底，窗口缩放后不出现空白边。
- 不引入第三方库，不使用 canvas、WebGL 或视频。
- 背景层不参与文档流，不产生额外滚动条，也不拦截指针事件。

## 降级与可访问性
- 系统开启「减弱动态效果」时：动画全部停止，保留一帧静态渐变，配色层次仍然成立。
- 背景层标记为装饰并从读屏顺序中移除，不作为焦点目标，不遮挡任何可点击元素。
- 正文放在不透明或高不透明度的承载层上，正文对比度不低于 4.5:1。
- 必须提供暂停入口，环境动画不能成为无法关闭的干扰。

## 验收
- 连续观察两个完整循环，无可见断层、无亮度跳变。
- 播放中滚动页面、缩放窗口，背景始终铺满视口，四边无黑边。
- 暂停后画面冻结，恢复后从冻结的帧继续，不回到起点。
- 开启减弱动态效果后画面静止，仍能辨认主色与渐变方向。
- 背景层之上所有文字可选中、按钮可点击，指针事件不被拦截。

## 不要做
- 不要加粒子、噪点、扫描线、网格线等额外装饰。
- 不要做鼠标跟随、滚动联动或随内容变化的交互。
- 不要让背景盖过正文，也不要为了饱和把配色提到刺眼。
- 不要把循环时长压到 6s 以内，也不要叠加闪烁与脉冲。
