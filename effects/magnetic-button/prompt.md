# 磁吸按钮

## 目标
指针靠近时按钮朝指针方向轻微偏移、离开后平滑回弹，用低成本动效增强关键行动按钮的触感。

## 触发与行为
- 指针进入按钮外缘向外 {{radius}} 的范围：按钮进入磁吸状态，目标位移以指针相对按钮中心的偏移量乘以 {{strength}} 为基准；指针越靠近按钮，实际系数越接近基准值，在感应边界处衰减到基准值的四分之一。
- 指针在范围内移动：按钮以每帧约 0.22 的插值逼近目标位移，只改变 transform，不改变尺寸与布局。
- 指针离开感应范围：退出磁吸状态，按钮以三次缓出曲线在 {{returnMs}} 内回到原位。
- 指针按下：保持当前位移并给出按压颜色反馈，不得跳位、缩放或抖动。
- 键盘聚焦：不产生任何位移，只显示 2px 焦点环。

## 参数
- {{strength}}：吸引强度，默认 0.3，建议 0.15–0.45；数值越大按钮越贴近指针。
- {{radius}}：影响半径，默认 120px，建议 80–200px；从按钮外缘向外计算。
- {{returnMs}}：回弹时长，默认 420ms，建议 280–600ms；数值越小回位越快。

## 技术中性约束
- 位移只能使用 transform 的 translate3d，位移绝对值上限固定为 24px，禁止改动 width、height、margin 或触发重排。
- 指针监听集中为一个共享监听，不为每个按钮单独绑定；指针移出窗口或页面滚动时必须复位。
- 每帧只更新 CSS 自定义属性，所有按钮归位后动画循环必须停止。
- 不引入任何第三方依赖，不使用 canvas 绘制。

## 降级与可访问性
- prefers-reduced-motion 下不执行磁吸位移计算，按钮保持静止，仅保留悬停变色与键盘焦点环。
- 触摸与粗略指针不启用磁吸，避免拖动页面时按钮抖动；按钮的点击行为不受影响。
- 磁吸只是增强，禁止把功能或文案只放在吸附状态里。

## 验收
- 指针从任意方向靠近，按钮偏移方向与指针一致，默认参数下最大偏移不超过 24px。
- 指针移出感应范围后，按钮在 {{returnMs}} 内回到 0 位移，无残留偏移。
- 连续快速划过按钮不闪烁，页面不出现横向滚动条或布局位移。
- 开启减弱动态效果、或使用触摸设备时，按钮位置与普通按钮完全一致。
- 键盘 Tab 能聚焦按钮，焦点环清晰可见。

## 不要做
- 不要加缩放、旋转、3D 倾斜或跟随光斑等额外效果。
- 不要让按钮偏离原位超过自身宽度的一半。
- 不要在触摸设备上启用磁吸。
- 不要用固定定时器伪造缓动，位移必须由指针位置驱动。
