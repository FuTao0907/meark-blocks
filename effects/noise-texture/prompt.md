# 噪点纹理

## 目标
在深色画面与图片上叠加一层细颗粒噪点，削弱大面积纯色的塑料感，让作品封面、海报与深色底栏呈现胶片或复古印刷的质感。

## 触发与行为
- 纹理随页面加载生成并铺满指定容器，静止时也有稳定、均匀的颗粒。
- 颗粒按 {{density}} 的密度随机分布，颗粒尺寸约 {{size}}px，整层透明度由 {{opacity}} 控制。
- 开启动效时，颗粒以约 12 帧/秒的间隔整体位移，形成轻微闪烁，位移步长取颗粒块的整数倍，避免出现滑动感。
- 容器或窗口尺寸变化时重设画布尺寸并重新平铺纹理，颗粒保持 1:1 像素，不被拉伸成条纹。
- 页面进入后台时停止刷新，回到前台继续；减弱动态效果时只绘制一帧。

## 参数
- {{density}}：颗粒密度，默认 0.35，建议 0.1–0.8；数值越高亮颗粒占比越大。
- {{opacity}}：纹理整体不透明度，默认 0.06，建议 0.03–0.15；超过 0.15 会明显影响文字可读性。
- {{size}}：颗粒基准尺寸，默认 1px，建议 1–3px；大于 3px 会从颗粒感变成马赛克。
- {{tint}}：颗粒颜色，默认 255, 255, 255（RGB 三元组），深色背景用浅色颗粒，浅色背景改为深色颗粒。

## 技术中性约束
- 不引入任何第三方依赖，图形全部由 Canvas 生成，不请求任何图片或字体资源。
- 噪点先生成到离屏画布再平铺到主画布，运行期不逐帧重建像素数据。
- 主画布 backing store 按设备像素比放大，绘制坐标使用 CSS 像素，1 个颗粒恒为 1 个 CSS 像素；resize 后重建 backing store 并重绘。
- 全场景只保留一个 requestAnimationFrame 循环，并通过时间戳限制到约 12 次/秒，不做满帧重绘。
- 纹理层不接收指针事件，不影响下方文字选择、链接点击与滚动。

## 降级与可访问性
- 系统开启「减弱动态效果」时：颗粒静止，只绘制一帧，不位移、不闪烁。
- 纹理叠加后，正文与其背景的对比度仍需不低于 4.5:1，允许按最亮颗粒计算。
- 纹理层对辅助技术隐藏，不承载语义信息，也不进入 Tab 焦点顺序。
- 不在 12px 以下的文字与表单控件上叠加纹理，避免降低可读性与输入准确性。

## 验收
- 打开页面即可看到均匀颗粒，放大到 200% 后无明显块状重复接缝。
- 纹理铺满容器四边，窗口缩放后无空白边、无缺角、无拉伸。
- 连续运行 5 分钟内存与 CPU 占用平稳，无逐帧创建大对象，rAF 回调恒为 1。
- 减弱动态效果下颗粒完全静止，静止画面仍能辨认颗粒质感。
- 纹理层下方的按钮、输入框与文本均可正常点击、选中与聚焦。

## 不要做
- 不要用外部图片或 base64 图片充当噪点。
- 不要叠加扫描线、漏光、划痕、暗角等其它复古滤镜元素。
- 不要每帧重新生成整幅像素数据，也不要为颗粒单独创建 DOM 节点。
- 不要在纹理层上绑定任何点击、悬停或拖拽事件。
