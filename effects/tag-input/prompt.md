# 标签输入

## 目标
在一个输入框内连续录入多个标签，以胶囊形式排列并可随时移除，同时用实时计数与上限提示避免超量。

## 触发与行为
- 焦点在输入框内输入文字，按 {{separator}} 提交：去除首尾空白后生成一个胶囊，输入框清空并保持焦点。
- 提交时依次校验：空串忽略；与已有标签重复（忽略大小写与首尾空格）时只提示不新增；超过 {{maxLength}} 个字符时截断后添加并提示；已达 {{maxTags}} 个时拒绝新增并提示上限。
- 粘贴含逗号、分号、制表符或换行的文本时，按这些分隔符拆成多个标签依次添加，超出 {{maxTags}} 的部分丢弃，并给出「已添加 N 个、M 个未添加」的汇总提示。
- 输入框为空时按 Backspace 删除最后一个标签；输入框为空时按 ← 把焦点移到最后一个标签的移除按钮；焦点在移除按钮上时，← → 在按钮之间移动，Backspace 或 Delete 删除当前标签，删除后焦点落到下一个按钮，没有下一个则回到输入框。
- 点击胶囊上的 × 删除对应标签并把焦点交还输入框；所有增删都通过 aria-live 状态区播报「已添加 X」「已移除 X」「已达上限 N 个」。

## 参数
- {{maxTags}}：标签数量上限，默认 8，建议 3–20；达到上限后输入框仍可聚焦，但提交只提示不新增。
- {{separator}}：提交按键，默认 Enter，也可换成逗号；不要用 Tab 作提交键，否则会破坏键盘焦点顺序。
- {{maxLength}}：单个标签最大字符数，默认 12，建议 8–24；超出部分截断，不整条拒绝。

## 技术中性约束
- 不引入任何第三方依赖。
- 标签以数据数组为唯一状态源，新增与删除走同一个渲染函数，胶囊、计数、推荐项状态不会不同步。
- 中文输入法组字期间（composition 未结束）按 Enter 只上屏候选词，不提交标签；同时识别键码 229 的兼容情况。
- 容器为可换行的弹性布局，标签增多时高度自然增长，不出现横向滚动条；单个标签超长时省略显示，不撑破容器。
- 焦点顺序与视觉顺序一致：已有标签在前、输入框在后；不使用自动聚焦抢走页面焦点。

## 降级与可访问性
- 每个胶囊的移除入口必须是可聚焦按钮，可访问名称形如「移除标签 前端」；纯图标 × 不能只有视觉含义。
- 状态区使用 role="status" 与 aria-live="polite"，播报增删与上限；相同文案连续出现时也要能再次播报。
- prefers-reduced-motion 下：去掉新增、删除时的缩放与抖动，只保留颜色和边框变化；上限提醒不得依赖闪烁。
- 上限提示不能只用红色表达，必须同时有文字说明；所有可聚焦控件有清晰的键盘焦点环。
- 标签文字可被选中复制，移除按钮的可点击区域不小于 18×18px。

## 验收
- 输入「前端」按 Enter 后出现胶囊，输入框清空且仍保持焦点。
- 连续提交同名标签不会产生第二个胶囊，状态区给出重复提示。
- 已满 {{maxTags}} 个时再提交，胶囊数量不增加，并出现明确的上限提示。
- 输入法组字过程中按 Enter 不会提交半成品拼音。
- 焦点在移除按钮上按 Delete 能移除对应标签，方向键可在标签之间移动。
- 开启减弱动态效果后没有任何缩放、抖动或闪烁。
- 刷新页面后胶囊、计数与推荐项高亮状态一致。

## 不要做
- 不要做下拉联想、远程搜索或标签云。
- 不要支持拖拽排序，也不要把标签做成可编辑的输入框。
- 不要在原生输入框之上叠加自绘光标或隐藏输入框。
- 不要把删除入口做成只在悬停时出现。
