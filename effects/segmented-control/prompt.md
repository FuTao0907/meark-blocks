# 分段控件

## 目标
在一行内提供 2–5 个互斥选项，用滑动指示块标出当前项，切换时内容同步更新，并且键盘可以完整操作。

## 触发与行为
- 点击任一分段：该段立即进入选中态，指示块在 {{duration}} 内从原位置滑到新位置，文字颜色与下方内容同步切换。
- 悬停未选中段：只改变文字颜色，指示块不移动、选中态不变。
- 键盘：Tab 只落在当前选中段；← → 在分段之间移动并同步选中；Home / End 跳到首项与末项；Enter 或空格对当前段执行一次确认。
- 内容区随选中项更新，做一次轻微的透明度过渡，容器高度保持不变，不出现跳动。
- 连续快速点击时，指示块从当前位置继续追向最新目标，不排队播放中间状态。

## 参数
- {{duration}}：指示块滑动时长，默认 220ms，建议 150–320ms；设为 0 时瞬时切换。
- {{height}}：控件高度，默认 36px，建议 28–44px；低于 28px 会削弱触控可用性。
- {{gap}}：分段之间的间距，默认 4px，建议 2–8px；间距变化后指示块位置必须重新测量。

## 技术中性约束
- 不引入任何第三方依赖。
- 指示块用绝对定位加 transform 位移，宽度与偏移由当前段的实测尺寸得出，不写死百分比。
- 只对 transform 与 opacity 做动画，不改变分段宽度，不触发重排。
- 分段数量与文案变化后无需改样式即可正确对齐；容器尺寸变化时重新测量。
- 同一控件内各分段等分宽度；指示块必须落在容器圆角内，不溢出。

## 降级与可访问性
- 使用 tablist / tab / tabpanel 语义，选中段 aria-selected="true"；未选中段 tabindex="-1"，通过方向键进入。
- 分段与面板用 aria-controls 与 aria-labelledby 关联；面板切换后 aria-labelledby 指向新的分段。
- 选中状态不能只靠颜色：选中段同时加粗文字并提高对比度。
- prefers-reduced-motion 下：指示块直接出现在目标位置，无滑动、无淡入淡出。
- 触控目标不小于 {{height}} 且不低于 28px；窄屏下不换行、不截断文字。

## 验收
- 点击第二段后，指示块与文字在 {{duration}} 内对齐，面板显示对应内容。
- Tab 只停在当前选中段，方向键可切换并同步焦点与选中态。
- 窗口宽度变化后指示块仍与选中段严格对齐，不出现半像素错位。
- 快速连点 5 次后指示块停在最后点击的段，没有抖动或残影。
- 开启减弱动态效果后切换是瞬时的，没有位移动画。
- 分段文案改为 2–5 个字后布局仍然等宽对齐。

## 不要做
- 不要做成多选，也不要加入「全部」这类隐含选项。
- 不要改用下划线式标签页或一排胶囊按钮来替代分段控件。
- 不要加音效、扫光、渐变流光等附加效果。
- 不要在切换时改变控件高度或让内容区上下跳动。
