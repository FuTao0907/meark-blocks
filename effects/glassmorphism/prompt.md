# 玻璃拟态

## 目标
把内容面板做成半透明磨砂玻璃，让背后的色彩与光斑透过面板被柔和模糊，形成层级清楚、可读不受损的悬浮表面。

## 触发与行为
- 面板常驻显示磨砂效果，不依赖滚动或悬停触发；背后的背景内容始终可辨但被模糊。
- 指针在页面内移动时，背景光斑以低幅度偏移跟随，位移不超过 24px，玻璃背后的颜色随之缓慢流动。
- 指针悬停面板时，面板上移 2px、边框亮度提高一档，离开后 200ms 内回到原位。
- 键盘聚焦面板或其内部可交互元素时，显示 2px 强调色焦点环，反馈与悬停态等价但不发生位移。
- 浏览器不支持背景模糊时，自动切换为不透明度 0.9 的实色面板，布局与文字位置保持一致。

## 参数
- {{blur}}：背景模糊半径，默认 16px，建议 8–28px；超过 28px 会让文字边缘发灰。
- {{opacity}}：玻璃底色不透明度，默认 0.12，建议 0.06–0.2；取值过高会盖住背景，过低会让文字失去依托。
- {{radius}}：面板圆角，默认 20px，建议 8–28px，需与卡片内边距协调。
- {{tint}}：玻璃色调，默认 255, 255, 255（RGB 三元组），深色背景用白色系，浅色背景改用深色系。

## 技术中性约束
- 不引入任何第三方依赖，只使用 CSS 背景模糊、rgba 背景与 1px 半透明描边。
- 模糊只作用于面板自身，不给整页或大区块设置滤镜，避免文字重影与滚动掉帧。
- 悬停位移只使用 transform 与边框颜色变化，不改变宽高与内边距，不触发重排。
- 面板内的文字、图标必须位于模糊层之上，且面板内部不再嵌套第二层背景模糊。
- 指针监听只绑定在演示容器范围内，页面卸载时移除监听。

## 降级与可访问性
- 系统开启「减弱动态效果」时：取消光斑偏移与悬停上移，只保留静态模糊、边框变化与焦点环。
- 不支持背景模糊时回退为实色面板，正文与背景的对比度不低于 4.5:1。
- 玻璃面板上的文字按最亮背景处校验对比度，禁止把次要信息做成 12px 以下并压在半透明层上。
- 焦点顺序与页面结构顺序一致，焦点环不被 overflow 裁切，鼠标悬停不是唯一的可交互信号。

## 验收
- 面板背后有彩色内容时能看到清晰模糊，面板边缘 1px 高光完整不断裂。
- 面板内文字在任何光斑位置下都可读，不发灰、不出现重影。
- 悬停与离开的过渡在 200ms 内完成，快速划过一排面板时不抖动、不闪烁。
- 关闭背景模糊能力后，面板位置、尺寸与文字排版均不发生位移。
- 减弱动态效果下无位移、无缩放，玻璃质感与焦点反馈仍然存在。

## 不要做
- 不要叠加 3D 倾斜、翻转、鼠标跟随高光或视差缩放。
- 不要给面板加噪点、扫描线、彩虹渐变动画或流光边框。
- 不要对整页使用滤镜，也不要多层嵌套背景模糊。
- 不要为了玻璃效果改写卡片内的字号、行高与文案排版。
