# 惯性拖拽

## 目标
让卡片可以按住拖动，松手后按初速度滑行、在边界反弹并因摩擦逐渐停住，提供有重量感的直接操作。

## 触发与行为
- 按住卡片：立即进入拖拽态，指针与卡片保持固定的抓取偏移，卡片跟随指针且不超出舞台边界。
- 拖动过程中：根据最近约 100ms 的指针位移估算速度，速度上限为 {{maxSpeed}}，作为松手后的初速度。
- 松手：以估算速度开始惯性滑行，每帧按 {{friction}} 的 60fps 当量衰减，撞到边界时反向并乘以 {{bounce}}。
- 速度低于 8px/s：立即停止、速度归零，不留下持续运行的动画循环。
- 键盘聚焦卡片：方向键每次移动 16px（按住 Shift 为 40px），不产生惯性；重置按钮把卡片放回舞台中心。

## 参数
- {{friction}}：每帧速度衰减系数（按 60fps 折算），默认 0.92，建议 0.86–0.96；越小停得越快。
- {{maxSpeed}}：松手速度上限，默认 2400px/s，建议 1200–3600px/s。
- {{bounce}}：边界反弹系数，默认 0.42，建议 0.2–0.6；0 表示撞墙即停。

## 技术中性约束
- 位置只通过 transform 的 translate3d 更新，不修改 left、top，不触发布局。
- 使用 pointer 事件与指针捕获，指针移出舞台后仍能继续拖动并正常松手。
- requestAnimationFrame 循环必须可取消，拖拽开始、松手、页面隐藏时都要停止上一轮循环。
- 不引入物理引擎或第三方依赖，速度估算与衰减自行实现。

## 降级与可访问性
- prefers-reduced-motion 下保留直接拖拽，但松手立即停止，不产生惯性滑行与边界反弹。
- 卡片可 Tab 聚焦，方向键可移动，重置按钮可用键盘触发。
- 触摸拖动用 touch-action 限制在卡片上，不阻断页面其它区域的滚动。

## 验收
- 慢速拖到任意位置松手，卡片停在原地不漂移。
- 快速甩出后卡片滑行、在边界反弹，并在 2s 内停住。
- 甩出速度再大也不超过 {{maxSpeed}}，卡片不会穿出舞台边界。
- 拖拽中切换标签页或缩放窗口，回来后动画不叠加、卡片仍在边界内。
- 减弱动态效果下松手即停，无惯性滑行。

## 不要做
- 不要加旋转、缩放或拖尾粒子。
- 不要用 CSS transition 模拟惯性，物理位移必须逐帧计算。
- 不要让卡片被拖出舞台或盖住操作栏。
- 不要用 setInterval 驱动动画。
