# 骨架屏

## 目标
在内容返回前用与最终布局同构的中性占位块占住空间，先稳定页面结构，数据到达后再替换成真实内容。

## 触发与行为
- 请求发起时进入骨架态，显示 {{rows}} 行占位；占位行高与真实行高一致。
- {{shimmer}} 为 1 时，微光每隔 {{shimmerDuration}} 从占位块左侧扫到右侧；为 0 时只保留静态灰块。
- 数据返回后 150ms 内完成替换：整体淡出骨架、淡入真实内容，并从文档中移除骨架节点。
- 切换前后卡片总高度不变，不做高度展开、行数变化或逐行错峰入场。
- 请求失败时退出骨架态并显示错误文案，不允许停留成永久骨架。

## 参数
- {{rows}}：占位行数，默认 4，建议 2–6，必须与真实内容的行数一致。
- {{shimmer}}：微光开关，默认 1（开），0 为关，只影响扫光不改变占位块尺寸。
- {{shimmerDuration}}：微光扫过周期，默认 1400ms，建议 1000–2200ms；越长越安静。

## 技术中性约束
- 骨架节点与真实内容共用同一行容器，行高由容器固定，不允许占位块用内容撑开高度。
- 扫光只用背景渐变加 transform 位移实现，不触发布局计算，也不逐帧修改宽度。
- 骨架不承载点击、悬停、焦点或表单行为，纯展示。
- 不引入第三方依赖，不使用任何外部图片、字体或图标资源。
- 骨架块使用中性灰蓝，不得放真实文案、图标或品牌色块冒充内容。

## 降级与可访问性
- 系统开启减弱动态时：取消扫光与淡入淡出，静态占位块与真实内容直接切换。
- 环境不支持动画时同样直接切换，不残留半透明过渡态。
- 加载中容器标记 aria-busy="true"，完成后置为 false；骨架节点对辅助技术隐藏。
- 用视觉隐藏的实时文本播报「正在加载 N 行内容」，完成时播报「加载完成」，不逐块朗读占位块。
- 加载状态不能只靠颜色表达，界面需同时有状态文字。

## 验收
- 骨架行数等于 {{rows}}，切换后真实行数与之相同。
- 加载中与加载完成两种状态下卡片高度差不超过 2px。
- {{shimmer}} 为 0 或系统减弱动态时，占位块完全静止。
- 快速反复切换时不出现骨架与真实内容同时可见，也不残留骨架节点。
- 请求失败时骨架消失且能看到错误文案。

## 不要做
- 不要加旋转 spinner、进度百分比或「正在加载...」的逐点动画。
- 不要在骨架块上放按钮、链接、假文字或图标。
- 不要用 setTimeout 伪造固定两秒后自动加载完成。
- 不要使用高饱和色、插画或真实内容截图填充占位块。
