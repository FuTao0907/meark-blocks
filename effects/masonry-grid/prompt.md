# 瀑布流布局

## 目标
让高度不等的卡片按列自上而下紧凑排列，消掉等高网格留下的竖向空洞，同时保持固定的阅读顺序与可预期的重排结果。

## 触发与行为
- 首次渲染：按 {{columns}} 计算列宽，卡片依次落入当前高度最小的列，容器高度取最高一列的高度。
- 卡片展开或收起：该卡片高度变化后整块重算位置，其余卡片在 {{reflowMs}} 内向新位置平移，末张卡片不被容器裁切。
- 容器宽度变化：按列宽阈值在 3 / 2 / 1 列之间切换，切换后立即重排，过程不出现卡片重叠。
- 卡片内容异步变高（图片、字体载入完成）：再触发一次重排，不使用写死的占位高度。
- 卸载或替换：取消未执行的帧回调，断开尺寸监听，移除卡片点击监听。

## 参数
- {{columns}}：桌面端列数，默认 3，建议 2–4；取 4 列时单卡摘要文字需压到 40 字以内。
- {{gap}}：卡片横向与纵向间距，默认 16px，建议 12–24px，两个方向的数值必须一致。
- {{reflowMs}}：重排时的位移过渡时长，默认 280ms，建议 200–400ms；超过 400ms 会显得拖沓。

## 技术中性约束
- 不引入任何第三方依赖。
- 列宽与位置来自同一套列计算，不混用 CSS 多列与绝对定位两套机制。
- 重排只写 transform 与容器高度，不逐帧写 top/left，不改动卡片内部排版。
- 列数与间距只在一处定义，不在样式与脚本里各写一份数字。
- 卡片高度由内容决定，不用固定高度裁切内容来凑整齐。

## 降级与可访问性
- 系统开启「减弱动态效果」时：取消位移动画，卡片直接出现在新位置，容器高度即时更新。
- 脚本不可用时：卡片按单列文档流依次排列，内容完整可读，不出现绝对定位造成的大片空白。
- 键盘焦点顺序等于 DOM 顺序；视觉列序可以与焦点顺序不同，但不得跳读、不得丢失焦点。
- 卡片用 Enter 与空格切换展开状态，并通过 aria-expanded 暴露当前状态。

## 验收
- 任意卡片高度组合下，相邻两列之间的竖向空隙不超过 {{gap}}。
- 连续展开收起 10 次后卡片不重叠、不漂移，容器高度与最末卡片底边对齐。
- 窗口从 1440px 缩到 360px，列数依次变为 2 与 1，卡片不溢出容器。
- 展开最后一张卡片时容器高度随之增长，底部留白不超过 {{gap}}。
- 开启减弱动态效果后，重排没有任何位移过渡。

## 不要做
- 不要给卡片加放大、发光、3D 倾斜等悬停效果，本块只负责排列。
- 不要用固定高度裁切卡片内容来伪造整齐。
- 不要引入无限加载、虚拟滚动或图片懒加载逻辑。
- 不要在重排时打乱 DOM 顺序去「优化」视觉列序。
