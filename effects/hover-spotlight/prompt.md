# 光斑跟随卡片

## 目标
卡片悬停时，在卡面内部生成一个跟随指针的光斑，把注意力引导到当前指向的卡片，同时不干扰阅读。

## 触发与行为
- 指针进入卡片：光斑从透明度 0 淡入到最大透明度，并开始跟随指针。
- 指针在卡片内移动：光斑中心跟随指针坐标，可保留极轻微延迟以形成柔和的拖尾感。
- 指针离开卡片：光斑在 {{fadeMs}} 内淡出，结束后完全隐藏，不残留。
- 键盘聚焦卡片时：不显示光斑，改为整卡边框高亮，保证键盘用户有等价反馈。

## 参数
- {{glowSize}}：光斑直径，默认 320px，建议 200–480px。
- {{glowOpacity}}：光斑最大透明度，默认 0.15，建议 0.08–0.25。
- {{fadeMs}}：淡出时长，默认 200ms，建议 120–300ms。
- {{glowColor}}：光斑颜色，默认暖白，需与卡面底色形成轻微对比。

## 技术中性约束
- 不引入任何第三方依赖。
- 不改变卡片尺寸、圆角与内部布局；光斑必须裁剪在卡片内部。
- 动画只使用 transform 与 opacity，不触发重排。
- 指针监听只绑定在卡片范围内，不绑定到文档级。

## 降级与可访问性
- 系统开启「减弱动态效果」时：不跟随、不淡入淡出，改为静态边框高亮。
- 触摸设备没有悬停：默认不启用，且不得把关键信息仅放在悬停态。
- 光斑不得压暗文字；文字层级始终位于光斑之上，保证对比度不下降。

## 验收
- 快速划过卡片时光斑不抖动、不闪烁。
- 指针移出后 300ms 内无残留光斑。
- 卡片内文字仍可正常选中，链接仍可点击。
- 开启减弱动态效果时没有位移动画。
- 触摸设备上不出现光斑。

## 不要做
- 不要加缩放、倾斜、3D 旋转等额外悬停效果。
- 不要改变卡片配色与阴影。
- 不要用 canvas 实现，渐变叠加即可，不要过度设计。
- 不要给光斑加粒子、噪点或扫描线。
